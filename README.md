# Akil Grunau Portfolio

Architecture portfolio website for Akil Grunau, presenting design work, study material, and professional profile information.

## Overview

This project is a static portfolio site built with plain HTML, CSS, and JavaScript. It includes:

- a hero section with motion/video presentation
- project and study sections
- portfolio PDF viewer
- Revit tutorial cards
- contact and social links

## Files

- `index.html` – site structure and content
- `styles.css` – design system, layout, and responsive styling
- `script.js` – mobile navigation interaction

## Run locally

From the project folder, start a local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/
```

## Deployment

This is a static website and can be deployed on Netlify or any similar static hosting service.

For Netlify, use the repository root as the publish directory and leave the build command empty.
